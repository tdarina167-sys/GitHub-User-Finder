# GitHub User Finder

## Автор
**Тедеева Дарина**

## Описание
GUI-приложение для поиска пользователей GitHub с использованием GitHub API. Позволяет искать пользователей, добавлять их в избранное и сохранять список в JSON-файл. Использует только встроенные модули Python.

## Требования
- Python 3.6+
- Интернет-соединение
